# برنامه تمرین ۴ هفته‌ای

یک برنامه وب (PWA) فارسی و راست‌به‌چپ، بدون نیاز به سرور یا نصب.

## اجرا
- فایل `index.html` را در مرورگر باز کن (دوبار کلیک).
- برای نصب روی گوشی و کار آفلاین، پوشه را روی یک میزبان HTTPS (مثل GitHub Pages) یا `python3 -m http.server` بگذار.

## ساختار
```
index.html          صفحه اصلی
manifest.json       تعریف PWA
sw.js               کش آفلاین
css/style.css       ظاهر
js/util.js          ابزار، ذخیره‌سازی، صدا
js/data.js          حرکت‌ها، راهنما، برنامه ۱۲ جلسه
js/engine.js        موتور انیمیشن سه‌بعدی (دوربین، اسکلت، عضلات)
js/exercises.js     پوز و دستگاه حرکت‌های برنامه
js/exercises2.js    پوز و دستگاه حرکت‌های کتابخانه سفارشی
js/library.js       حرکت‌های اضافه، پیش‌فرض‌ها و جدول کالری
js/calories.js      محاسبه کالری (MET)
js/custom.js        ساخت و اجرای جلسه سفارشی
js/main.js          راه‌اندازی
js/app.js           رابط کاربری و جلسه تمرین
icons/              آیکون‌ها
```

## افزودن حرکت جدید
1. در `js/data.js` نام، `GUIDE` و `MACH` را اضافه کن.
2. در `js/exercises.js` یک `EX.xx` با کلیدهای پوز و (اختیاری) `pl / rb3 / rf` برای دستگاه بساز.

فونت وزیرمتن از Google Fonts بارگذاری می‌شود؛ بدون اینترنت از Tahoma استفاده می‌شود.

## کالری
کالری = (MET + بونوس بار) × وزن بدن × مدت. مدت هر ست از تعداد تکرار یا ثانیه واقعی، استراحت‌ها از زمان واقعی، و گرم‌کردن/هوازی/سرد کردن از مدت هر مرحله حساب می‌شود. جدول `CAL` در `js/library.js` قابل ویرایش است. خروجی تخمین است (±۲۵٪).

## جلسه سفارشی
تب «سفارشی» → ساخت جلسه یا قالب آماده → افزودن حرکت از کتابخانه (۳۷ حرکت، با جستجو و فیلتر) → تنظیم ست، تکرار و استراحت → ذخیره و شروع.
