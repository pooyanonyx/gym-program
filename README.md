# برنامه تمرین ۴ هفته‌ای

یک برنامه وب (PWA) فارسی و راست‌به‌چپ، بدون نیاز به سرور یا نصب.

## اجرا
- فایل `index.html` را در مرورگر باز کن (دوبار کلیک).
- برای نصب روی گوشی و کار آفلاین، پوشه را روی یک میزبان HTTPS (مثل GitHub Pages) یا `python3 -m http.server` بگذار.

## ساختار
```
index.html          صفحه اصلی
manifest.json       تعریف PWA
sw.js               کش آفلاین
css/style.css       ظاهر
js/util.js          ابزار، ذخیره‌سازی، صدا
js/data.js          حرکت‌ها، راهنما، برنامه ۱۲ جلسه
js/engine.js        موتور انیمیشن سه‌بعدی (دوربین، اسکلت، عضلات)
js/exercises.js     پوز و دستگاه هر حرکت
js/app.js           رابط کاربری و جلسه تمرین
icons/              آیکون‌ها
```

## افزودن حرکت جدید
1. در `js/data.js` نام، `GUIDE` و `MACH` را اضافه کن.
2. در `js/exercises.js` یک `EX.xx` با کلیدهای پوز و (اختیاری) `pl / rb3 / rf` برای دستگاه بساز.

فونت وزیرمتن از Google Fonts بارگذاری می‌شود؛ بدون اینترنت از Tahoma استفاده می‌شود.
